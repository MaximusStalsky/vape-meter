# Интерфейс Vape Meter

MainView строит обзор, историю, аналитику и настройки нативными элементами Avalonia. Оболочка Windows задаёт заголовок, размещает MainView и добавляет StyleInclude для Styles/VapeTheme.axaml после FluentTheme. Цвета для обеих тем определены общими ресурсами.

Новый экран задаётся объектом Section в конструкторе MainView. Регистрация создаёт кнопку в боковом и нижнем меню. Функция Build возвращает содержимое экрана. CalendarView, InsightsView и SettingsView содержат соответствующие сценарии, а VapeVisuals собирает повторно используемые элементы. Основные кнопки и поля имеют идентификаторы для UI Automation.

Служба синхронизации вызывается при запуске, после локальных изменений и по кнопке. Индикатор показывает состояние обмена и очередь. На коротких окнах обзор уплотняет календарь и график, на узких сохраняет вертикальную компоновку.

MainView принимает рабочее хранилище и необязательные параметры платформы. Если Windows рисует общий фон за шапкой и содержимым, useHostBackdrop включает прозрачный фон MainView. Два callback-параметра getCloseToTray и setCloseToTray подключают настройку действия кнопки закрытия.
