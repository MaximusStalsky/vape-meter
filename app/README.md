# Vape Meter для Windows

Нативное приложение Avalonia для Windows 11 x64. Скрипт `publish-windows.ps1` публикует самодостаточный EXE. Состояние приложения хранится в `%LOCALAPPDATA%\VapeMeter`.

## Использование

- Записи ведутся с календаря через кнопку выбранной даты или её контекстное меню. После правки сразу пересчитываются история, статистика и прогноз.
- Обзор рассчитан на окно 1140 × 844 и развёрнутый режим. Длинная история и компактные окна используют прокрутку.
- В разделе «Настройки → Оформление и окно» выбирается действие крестика. По умолчанию он завершает приложение. Обычное сворачивание отправляет окно в трей. Команда «Выход» в трее завершает процесс.
- На Timeweb хранится общая история. Локальная SQLite содержит её кэш и очередь отправки. Клиент запускает обмен при открытии и после сохранения изменений. При недоступности сети записи остаются в очереди. Кнопка в настройках позволяет повторить обмен вручную.
- Windows-клиент ищет подготовленный DPAPI-ключ текущего пользователя. В другой учётной записи при отсутствии ключа доступна автономная работа.
- Изолированная проверка запускается с `--offline --data-dir "<абсолютный путь>"`.

## Структура

| Проект | Ответственность |
| --- | --- |
| VapeMeter.Windows | Запуск, кастомное окно, системные углы, трей, настройки окна, локальные пути и DPAPI |
| VapeMeter.Android | Запуск на телефоне, Android Keystore и экран подключения |
| VapeMeter.UI | Навигация, общие компоненты интерфейса, страницы, дизайн и диалоги |
| VapeMeter.Core | SQLite, очередь операций, импорт, резервные копии и протокол синхронизации |
| VapeMeter.Analytics | Расчёты календаря, интервалов, статистики и прогноза |

Навигация описана в списке страниц `MainView`. Для добавления экрана создайте компонент или файл страницы и зарегистрируйте название, описание, символ и функцию построения. Страница использует общие компоненты и ресурсы темы. Вычисления находятся в Analytics, операции с сохранением и обменом — в Core. Android-версия подключает те же три общих проекта и использует собственные реализации системных функций.

## Сборка

```powershell
.\publish-windows.ps1
```

По умолчанию скрипт выдаёт EXE Windows x64 в `dist\Vape Meter 1.0`. Решение `VapeMeter.slnx` объединяет пять проектов. Комплект разработки описан в `toolchain\README.md`, протокол — в `backend\README.md`.
