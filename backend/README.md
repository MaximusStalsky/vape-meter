# Vape Meter Backend

Персональный сервис синхронизации на .NET 10 и SQLite. Сервис по умолчанию слушает 127.0.0.1:18787. Внешний доступ предоставляется через HTTPS.

## API v1

Передавай User-Agent: VapeMeter/1.0. Cloudflare на этой зоне отклоняет часть стандартных User-Agent библиотек.

| Метод | Авторизация | Ответ |
| --- | --- | --- |
| GET /healthz | Открыт | HTTP 200 и состояние процесса |
| GET /v1/state | Bearer-токен устройства | datasetId, revision, records и ETag. При совпадении If-None-Match возвращается HTTP 304 |
| POST /v1/operations | Bearer-токен устройства | Результат одной сохранённой локально операции |

Клиент берёт datasetId из первого снимка. Запись содержит UUID, дату YYYY-MM-DD, version и deleted. Удалённые записи передаются с deleted=true. Они не учитываются в истории и статистике, но позволяют согласовать удаления на устройствах, которые долго были офлайн.

Пример добавления записи:

```json
{
  "datasetId": "ee8726de-a553-465d-b4f5-b45641076ed0",
  "operationId": "5aa13c58-6dd6-4ff7-ab05-5153edff075a",
  "recordId": "b7a9eaac-8a11-4bb8-be79-19a9f4f84642",
  "expectedVersion": 0,
  "action": "upsert",
  "date": "2026-11-22"
}
```

Для исправления даты передай текущую известную версию записи и новую дату. Для удаления передай action=delete, текущую известную версию и date=null. Повтор после сетевой ошибки отправляется тем же устройством с тем же operationId и тем же содержимым. Сервер сохраняет результат операции, поэтому результат повтора может содержать более раннюю ревизию. Для отображения актуальной истории клиент после отправки очереди обновляет снимок.

HTTP 409 возвращает код outcome. version_conflict содержит последнюю серверную версию записи, duplicate_date содержит запись, уже занимающую дату, operation_id_reused означает повтор UUID с другим содержимым или ключом, dataset_changed требует заново загрузить снимок и согласовать отложенные операции с новым набором данных. После решения конфликта новое изменение получает новый operationId. При временном HTTP 503 исходная операция остаётся в локальной очереди и отправляется повторно с задержкой.

## Сборка и проверка

Из папки backend в PowerShell:

```powershell
& '..\toolchain\dotnet\dotnet.exe' build -c Release
python -B '.\smoke.py' '..\toolchain\dotnet\dotnet.exe' '.\bin\Release\net10.0\VapeMeter.Backend.dll'
& '..\toolchain\dotnet\dotnet.exe' publish -c Release -r linux-x64 --self-contained -o '.\publish\linux-x64'
```

Для локального запуска с собственной базой установи VAPEMETER_DATA_DIR и VAPEMETER_DEVICE_CREDENTIALS. Второй параметр указывает JSON-словарь device → SHA-256 в hex от полного токена device.secret. VAPEMETER_PORT позволяет выбрать свободный порт, по умолчанию 18787. Интеграционная проверка сама создаёт и удаляет временную базу и процесс.
